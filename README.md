# 🍕 Bella Napoli

Proyecto web para una pizzería italiana ficticia llamada **Bella Napoli**, enfocada en transmitir tradición, sabor y una identidad visual elegante inspirada en la cocina italiana.

## 📌 Descripción
Bella Napoli es una landing page desarrollada con **HTML y CSS**, que presenta una estructura moderna con secciones como:
- Header con navegación fija
- Hero principal con llamada a la acción
- Sección *Sobre Nosotros* destacando la experiencia y tradición de la marca

El diseño prioriza la estética, tipografía limpia y una experiencia visual atractiva.

## 🛠️ Tecnologías utilizadas
- HTML5
- CSS3
- Google Fonts (Work Sans)
- Material Symbols Icons


## 🎨 Características destacadas
- Diseño responsive básico
- Header fijo
- Uso de variables CSS
- Texto flotante sobre imagen con posicionamiento absoluto
- Estilo moderno y limpio
